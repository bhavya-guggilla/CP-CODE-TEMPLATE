# 🎬 Movie Guessing Game

A modern movie guessing game built using HTML, CSS, and JavaScript.

## Features

* 🎯 Multiple difficulty levels (Easy, Medium, Hard)
* 🌎 Language filtering

  * English
  * Hindi
  * Telugu
  * Malayalam
* 💡 Hint system
* ❤️ Lives system
* 🏆 Score tracking
* ⌨️ Keyboard support
* 📱 Responsive design
* ✨ Modern UI with animations

## Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)

## How to Play

1. Select a language.
2. Choose a difficulty level.
3. Guess letters using the keyboard.
4. Reveal the movie title before running out of lives.
5. Use hints strategically to maximize your score.
